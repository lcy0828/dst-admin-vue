# DST Admin 功能真值

更新时间：2026-08-09。本文记录当前两个功能分支的真实能力，不把设计稿、占位页面或未来计划算作已完成。

## 状态定义

- **可用**：已有真实接口和用户入口，并通过自动测试、构建或本机真实 DST 环境验证。
- **部分可用**：主流程存在，但平台、远程节点、自动化验收或次要动作仍有明确边界。
- **未实现**：没有可交付的真实流程；即使仓库存在旧文件或占位页面，也不计为可用。

## 当前发布基线

| 范围 | 状态 | 事实 |
| --- | --- | --- |
| 前端技术栈 | 可用 | Vue 3.5、Vue Router 4、shadcn-vue/Reka UI、Tailwind CSS 4 |
| 正式界面 | 可用 | `/dashboard` 及全部正式业务路由使用 shadcn 布局；`/preview-v2/*` 仅作兼容重定向 |
| 数据来源 | 可用 | 业务页面读取真实后端接口，不使用演示或随机数据替代失败响应 |
| 默认运行目标 | 可用 | 默认管理本机；远程 Agent 必须单独配置和选择 |
| 自动质量门禁 | 部分可用 | 前端 lint、29 项 Node 测试和生产构建已接入；尚无浏览器 E2E |

## 功能矩阵

| 领域 | 本机 | 远程 Agent | 证据与边界 |
| --- | --- | --- | --- |
| 首次管理员、登录、退出、修改密码 | 可用 | 不适用 | `/api/v2/auth/*`；密码最少 6 位；会话、CSRF 和写请求幂等保护由后端提供 |
| 服务总览 | 可用 | 部分可用 | 展示真实房间、分片和系统状态；远程选择时只显示已开放的 Agent 范围 |
| 房间发现、接管、创建、编辑、删除 | 可用 | 未实现 | 真实存档目录与 `/api/v2/rooms`；远程请求会被边界拦截，不会误落到本机 |
| Master/Caves 启动、停止、重启 | 可用 | 未实现 | Job 驱动；覆盖 `stopped/starting/running/failed`，失败或超时启动会清理会话 |
| 世界创建与配置 | 可用 | 未实现 | 完整森林/洞穴模板、配置 Diff、revision、保护备份和原子写入 |
| 世界详情、天数、季节和状态 | 可用 | 未实现 | 读取真实分片状态；未运行或不可读取时显示明确状态 |
| 实时日志 | 可用 | 未实现 | 日志快照、下载和 SSE；支持断开后的事件恢复边界 |
| 结构化日志查询与规则 | 可用 | 未实现 | 使用稳定房间/世界 ID；支持显式解析最新日志、任务结果、正文与类型检索、分页、清理和规则创建 |
| Lua 控制台与参数化命令 | 可用 | 未实现 | 高风险原始命令要求明确房间确认；保留用于复杂 Mod 和管理命令 |
| 玩家、私信、踢出、封禁和名单 | 可用 | 未实现 | 玩家页、封禁页、房间特殊名单均使用真实 API |
| Workshop 搜索、下载、更新、修复、卸载 | 可用 | 未实现 | Steam 元数据与 Job 流程；下载成功不等同于已加载 |
| Mod 配置解析与编辑 | 部分可用 | 未实现 | Go/gopher-lua 主路径，外部 Lua 与 Python/Lupa fallback；当前 macOS 未安装外部 fallback 运行时 |
| 备份创建、上传、下载、恢复、删除 | 可用 | 未实现 | 真实备份目录和异步 Job；恢复到原房间可用，恢复到新房间未开放 |
| 地图渲染和 Session 诊断 | 部分可用 | 未实现 | 后端已有地图与存档诊断接口；前端尚无完整正式入口 |
| 公告 | 可用 | 未实现 | 公告管理页使用真实后端动作 |
| 自动化任务、任务组、日志和统计 | 可用 | 未实现 | 创建、编辑、执行、导入导出和历史结果均有正式路由 |
| Agent 注册、状态、配置和密钥轮换 | 可用 | 可用 | Agent 页面与运行目标配置可用；密钥常规读取仅返回掩码和指纹 |
| Agent 领域动作 | 不适用 | 部分可用 | 当前只开放 `system.refresh` 和 `disk.inspect`；任意 shell/script/custom 不属于生产 API |
| 系统设置与运行诊断 | 可用 | 部分可用 | 本机设置、版本、路径与 Mod fallback readiness 可用；远程仅限 Agent 已开放诊断 |
| 界面主题 | 可用 | 不适用 | Shadcn 中性为默认；预设、自定义主色和浅色/深色模式统一驱动语义 token |
| macOS 专服 | 可用 | 未验证 | 支持 Steam App 安装路径、空格路径、tmux 时间戳差异；已在本机 Master/Caves 联机验证 |
| Linux 专服 | 部分可用 | 未验证 | 路径和进程模型已实现，但本轮没有真实 Linux DST 回归证据 |
| Windows 专服 | 未实现 | 未实现 | 当前运行时依赖 tmux/Unix 进程模型，不应宣称兼容 |

## Mod 兼容结论

Mod 读取顺序固定为：内嵌 gopher-lua、外部 Lua、Python/Lupa。保留 Lua fallback 是为了兼容使用复杂 Lua 行为的 Mod；Go 主路径失败时不能伪造空配置或静默丢字段。

在 `192.168.2.12` 的 46 个已安装 Workshop Mod 样本中，Go 主解析和新内嵌 fallback helper 都达到 46/46。该结果是当前样本证据，不等于对未来所有未知 Mod 的数学保证。

## 发布前人工验收

在浏览器 E2E 接入前，发布必须使用真实后端手工完成：登录、正式侧栏导航、创建房间、Master/Caves 启停、失败重试、Mod 搜索与配置、玩家动作、备份恢复、日志 SSE、结构化日志解析与检索、Lua 控制台确认、远程目标拦截和移动端关键页面检查。

任何“暂无数据”都必须能和“加载失败”“功能未开放”区分；任何远程未实现动作都必须被阻止，不能调用本机服务作为 fallback。
