# DST character avatars

These 128x128 WebP files are derived from the official DST dedicated-server
`saveslot_portraits` atlas. They were generated by the companion DST asset
pipeline as release `dst-747465-eb3365fa493e-adf581806134`, with source hashes
and atlas provenance recorded in its `beacon-assets.json` manifest.

Only derived WebP images are published here; raw Klei TEX and XML files are not
included.
