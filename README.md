# 饥荒游戏后台管理系统

一个基于Vue.js和Element UI的饥荒游戏服务器管理系统前端界面。

## 功能特点

- 服务器状态监控与管理
- 在线玩家管理（查看、私信、踢出、封禁）
- 模组管理
- 存档备份
- 资源使用监控
- 季节、天数监控
- 系统事件日志
- 快捷操作（重启、重置世界等）

## 界面预览

饥荒后台管理系统具有美观的界面设计：
- 深色侧边栏导航
- 统计卡片实时展示信息
- 表格清晰展示服务器和玩家信息
- 响应式布局适应不同设备

## 技术栈

- Vue.js 2.x
- Element UI
- ES6+

## 安装与运行

1. 安装依赖：
   ```
   npm install
   ```

2. 开发环境运行：
   ```
   npm run serve
   ```

3. 构建生产环境：
   ```
   npm run build
   ```

## 定制化

可以根据具体需求修改以下内容：
- 服务器类型和配置
- 角色类型
- 快捷操作功能
- 管理员权限
- 主题颜色和样式
